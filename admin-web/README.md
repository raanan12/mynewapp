# ניהול · החסד היומי

לוח ניהול נפרד מהאפליקציה. משתמש רק ב-Supabase anon key (אותו מנגנון RLS
שמגן על כל שאר האפליקציה) - **אין כאן שום קוד שנוגע בכרטיסי אשראי, טוקנים,
או חיובים**. אין `service_role` key, ואין קריאה ל-`kesher-charge`.

## הרצה מקומית

```bash
cd admin-web
npm install
cp .env.example .env.local   # למלא VITE_SUPABASE_URL ו-VITE_SUPABASE_ANON_KEY
npm run dev
```

## פריסה ל-Vercel

1. `vercel.com` → New Project → יבוא מה-repo הזה.
2. **Root Directory**: `admin-web` (חשוב - זה תיקייה נפרדת בתוך הריפו).
3. Environment Variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
   (אותם ערכים כמו ב-`.env.local` של האפליקציה - שניהם ציבוריים, בטוח לשתף).
4. Build Command / Output Directory - ברירת המחדל של Vite עובדת (`npm run
   build`, `dist`).

## הרשאות

הכניסה דורשת משתמש עם `is_admin = true` בטבלת `profiles` (נוצר ב-SQL Editor,
ראו את [supabase/schema.sql](../supabase/schema.sql) ואת ההסבר הקודם על
יצירת מנהל). מייל+סיסמה, לא אנונימי.

## מה אפשר לערוך

- **נתונים**: סטטיסטיקות (משתמשים, תרומות, פילוח לפי קטגוריה, גרף 30 יום).
- **קטגוריות תרומה**: "למה אפשר לתרום" - שם, תיאור, אייקון, סדר הופעה, פעיל/לא.
- **סכומי מטבעות**: הכפתורים במסך הנתינה.
- **ארגונים**: הארגונים הנתמכים בכל קטגוריה.
- **ציטוטים**: הציטוט היומי.
- **הסכמות**: מכתבי הסכמה מרבנים (התמונה עצמה מועלית ל-Supabase Storage
  בנפרד, כאן מדביקים רק את הקישור).

שינויים כאן משפיעים על האפליקציה בפעם הבאה שהיא מסתנכרנת (בכל פתיחה/חזרה
לפורגראונד) - אין צורך בעדכון גרסה.
